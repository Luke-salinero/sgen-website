# Getting Results

After a job completes, you can retrieve the final output using `sgen.results(job_id, api_key)`.

Results are only available once the job has finished processing. If the job is still running, the SDK returns `None` and you should continue polling.

---

## Example Code

```python
import time
import sgen

API_KEY = "sk_live_123456789"

config = sgen.load_config("config.json")

job = sgen.quick_submit(config, api_key=API_KEY)
job_id = job["job_id"]

print("Submitted:", job_id)

# Poll until completed (recommended)
while True:
    st = sgen.status(job_id=job_id, api_key=API_KEY)

    if st is not None and st["status"] == "completed":
        break

    if st is not None and st["status"] == "failed":
        raise RuntimeError(f"Job failed: {st.get('error')}")

    time.sleep(5)

# Fetch final results
res = sgen.results(job_id=job_id, api_key=API_KEY)
print("Results:", res)
```

---

## Example Response (Completed)

When results are ready, the response is a JSON object returned by the gateway (example shape):

```python
{
  "job_id": "b10425d6-c8eb-4ccb-8f93-a731bbe7d616",
  "n" : 15
  "k" : 4
  "valid_candidates": [
    "010101010101",
    "001011010110"
  ],
}
```
---

## Recommended Pattern

The most reliable workflow is:

1. Submit with `quick_submit()`
2. Poll with `status()` until `"completed"`
3. Retrieve with `results()`

---

## Troubleshooting

### results() returns None

- The job is still running, or results are not ready yet.
- Poll `status()` until it reports `"completed"`, then call `results()` again.

### 404 Job not found

- The job ID does not exist, or your API key is not authorized for that job.
